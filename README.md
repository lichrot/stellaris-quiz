# [stellaris-quiz] Uzbekistan-based Charity Website

[![Netlify Status](https://api.netlify.com/api/v1/badges/528e339d-6559-4a3d-8b98-aba10e3ac2ae/deploy-status)](https://app.netlify.com/projects/stellaris-quiz/deploys)

A website made with [Astro](https://astro.build) for non-profit charity org "Stellaris Autism Society".

## [🖥️] Commands

```bash
# Development
pnpm run dev --port 3000

# Building
pnpm run build

# Preview
pnpm run preview --port 3000
```
